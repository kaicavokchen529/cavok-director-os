# Failure: Weightless Action

## Symptom

人物滑步、漂浮、起跳无蹬地、受击无方向、攻击没有准备和回收、重武器像无重量。

## Cause

只描述结果动作，没有Preparation、Weight Transfer、Contact、Inertia和Recovery。

## Fix

用 Anticipation → Weight Transfer → Acceleration → Contact → Compression → Follow Through → Recovery。明确支撑脚、髋肩旋转、受力方向、落地和二次惯性。

## Rule

真实动作先有重心，再有速度；先有接触，再有冲击。
