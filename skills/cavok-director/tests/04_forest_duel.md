# Test 04 — Forest Duel

Brief: two fighters begin 8m apart in a bright forest with large roots and one elevated branch. One uses a blade, one uses ranged ice.

Must test: combat geography, attack vectors, branch/root obstacles, daylight exposure, stable action masters, reposition and recovery.

Fail if: screen direction swaps, fighters teleport without re-anchor, camera and actors both move so fast that distance is lost.
