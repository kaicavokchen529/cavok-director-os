# Test 05 — Fire vs Ice

Brief: three transparent ice spears collide with one physically simulated fire attack in hard daylight.

Must test: exact count, source/propagation, ice transparency/refraction, combustion structure, thermal collision, steam, fracture, local interactive light, residue.

Fail if: blue glowing crystal, orange solid ball, generic spherical explosion, global blue/orange grade, all debris responds same frame.
