# Test 06 — Hyper-Speed Assault

Brief: one swordsman performs a multi-vector high-speed assault ending in a single finisher.

Must test: readable launch, compressed travel, reappearance vectors, temporal echoes not clones, varied trail lengths, rhythm break, finisher-only impact treatment, target geography.

Fail if: constant slow motion, permanent aura, identical crescent trails, every strike uses hit stop, target position becomes unknowable.
