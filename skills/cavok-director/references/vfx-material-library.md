# Cinematic VFX Material Library

## 核心原则

VFX材质必须同时回答：它由什么构成、如何生成、如何受光、如何运动、如何与环境接触、如何破坏、如何消散。禁止只用颜色形容特效。

## Ice / Frost

材质：透明冰体、晶体纹理、内部气泡、微裂纹、湿润表面、局部霜层。
形成：空气降温 → 水汽凝结 → 霜核 → 晶体骨架 → 轴向生长。
光学：折射、全反射、高光边缘、环境色轻微映入；主体不是自发蓝光。
接触：碎冰、冷凝白雾、霜扩散、局部冻结、水滴。
消散：裂纹 → 崩解 → 融化 → 水汽/水滴。
禁止：塑料水晶、霓虹蓝、整片环境染蓝。

## Fire / Combustion

材质：真实燃烧层级，白热或黄白核心、橙黄中层、深橙/暗红外焰、少量烟与炭化颗粒。
形成：热扰动 → 点燃/释放 → 火流 → 卷吸氧气 → 火焰扩张。
光学：动态暖色反射、局部过曝、热浪折射。
接触：树叶卷曲、表面炭化、热空气上升、烟、火星。
消散：燃烧减弱 → 火舌破碎 → 火星 → 烟 → 余热。
禁止：实体橙色球、持续均匀发光、整场景变夜景橙色。

## Lightning / Electricity

材质：分叉电弧、短寿命等离子通道、空气电离。
形成：电荷积累 → 预放电微弧 → 主放电路径 → 分支扩展。
光学：极短高亮核心，局部蓝白/紫白，可产生瞬时曝光抬升。
接触：火花、灼痕、金属导电路径、毛发轻微带电、空气臭氧感的声音设计。
消散：主弧断裂 → 分支余弧 → 少量烟/灼痕。
禁止：持续稳定的紫色光鞭、无来源电流。

## Plasma / Energy Blade

材质：高温电离气体或受约束能量层，不等于实体霓虹灯。
结构：高亮核心 + 半透明能量鞘层 + 轻微空气折射。
接触：表面灼切、局部熔融、火星、蒸汽或碎屑。
消散：亮度降低 → 能量鞘破碎 → 核心收缩。

## Smoke / Vapor

区分：烟来自燃烧颗粒；蒸汽来自相变；冷雾来自空气冷凝。
运动必须受温差、风、重力、障碍物影响，不能均匀漂浮。
逆光时体积可见，顺光时更克制。

## Dust / Debris

灰尘按颗粒尺度分层：细尘形成体积，较大碎片体现冲击方向。
冲击后必须存在启动延迟、加速度、抛物线、落地和二次弹跳。
禁止满屏随机粒子。

## Water

材质：表面张力、反射、折射、液滴、薄膜、飞溅。
高速水流需要主流体 + 边缘雾化 + 大液滴分离。
接触必须产生湿润痕迹和二次飞溅。

## Spatial Distortion / Portal

不是发光圆环。优先表现：背景折射、局部空间拉伸、视差异常、边缘色散、空气密度变化。
形成：局部折射异常 → 轮廓建立 → 空间开口/重构。
消散：边缘收缩 → 折射恢复 → 残留空气扰动。

## Shadow / Dark Matter

暗系VFX不是纯黑贴片。可使用吸光、局部对比压低、边缘烟化、空间遮蔽和低反射材质。
必须说明它是否实体化、流体化或仅改变光传播。

## Dissolve / Reconstruction

粒子消散：明确方向、粒径、速度和剩余材质。
灰烬：受重力与空气流动。
能量：发光强度随时间和距离衰减。
重构：先出现局部介质/轮廓，再恢复体积、衣物、材质与光照。

## Material Prompt Contract

每个重要VFX至少写：
Source / Material / Surface / Internal Structure / Optical Response / Motion / Contact / Secondary Effects / Dissipation。

目标：让VFX像摄影机前真实存在的异常材料，而不是游戏技能贴图。
