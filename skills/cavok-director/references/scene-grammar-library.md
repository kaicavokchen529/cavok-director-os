# Scene Grammar Library

## Purpose

Scene grammar describes how a type of scene organizes information, performance, blocking, rhythm, camera duties, sound and payoff. It is not a fixed shot list. Grammar answers **how the scene develops**; camera modules answer **how each beat is photographed**.

## Core grammar

Entry State → Dramatic Question → Information Control → Escalation → Reversal / Reveal → Payoff → Consequence → Exit State

For every scene type define:

- dramatic purpose and audience question;
- entry/exit state;
- viewpoint ownership and information order;
- relationship/power curve;
- blocking milestones;
- camera duties, not mandatory shots;
- sound/silence duties;
- escalation rule;
- payoff and aftermath;
- common failure modes.

## Selection rule

Choose the closest grammar, then adapt it to the actual characters, geography and genre. Never force a scene to hit every beat. Merge, remove or reorder beats when story logic requires it.

## Combination

A sequence may chain grammars, e.g. Boss Reveal → Dialogue Confrontation → Superpower Battle → Aftermath. Mark the handoff state so the next grammar inherits geography, power, damage, information and emotional state.
