# Hyper-Speed Assault Grammar

Lock target → readable launch preparation → explosive start → compressed/unreadable travel → reappearance from a new attack vector → clear contact/result → temporal echo decays → vector changes accelerate → short rhythm break → finisher → long enough residual/aftermath.

Speed must preserve cause and result. Do not show every centimeter of travel. Use temporal omission, directional stretch, low-detail afterimages and delayed environmental response. Re-anchor target position often enough to retain geography.

Finisher may use micro-suspension → snap acceleration → impact frame → deformation → recovery. Ordinary strikes should not all use finisher-level treatment.

Failure: clones instead of echoes, identical trails, constant slow motion, full-screen blue aura, unreadable target geography.
