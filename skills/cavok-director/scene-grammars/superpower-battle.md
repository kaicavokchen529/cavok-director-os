# Superpower Battle Grammar

Geography → ability tell/precursor → first probe → defense/counter → spatial reposition → rule discovery → escalation → ability interaction → collision/turn → consequence → new tactical state.

Treat powers as systems with source, cost, range, obstruction, recoil and environmental evidence. Keep partner/friendly-fire clearance readable. Each escalation should reveal a new rule or increase cost, not merely add brightness.

For major contact load VFX timing/impact/deformation and compositing modules.

Failure: skill spam, source-less effects, battlefield geometry ignored, environment unaffected, no recovery/cost.
