# Suspense Discovery Grammar

Known safe state → ambiguous cue → orientation → search → false/partial answer → stronger cue → recognition → reveal → reaction → consequence.

Decide what the audience knows relative to the character. Use offscreen sound, occlusion, negative space, focus and POV relay to control information. Let eyes react before head/body/camera.

Camera should often wait, pan/tilt only after a cue, then decelerate and settle on discovery.

Failure: camera reveals threat before character notices without intentional dramatic irony; constant handheld; every cue immediately explained.
