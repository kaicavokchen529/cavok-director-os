# Character Bible

## 核心原则

角色必须在跨镜头、跨Part、跨场景中保持身份稳定。角色Bible负责锁定不会随镜头随意变化的特征，以及允许变化的状态。

## Identity Lock

每个角色至少记录：

- Name / Alias
- Reference Image
- Age Range
- Height / Body Proportion
- Face Shape / Key Facial Features
- Hair Style / Length / Color
- Eyes / Glasses / Accessories
- Costume Layers
- Shoes
- Weapons / Props
- Dominant Hand
- Default Posture
- Walk / Movement Signature
- Performance Signature
- Combat Signature

## Costume Continuity

服装按层记录：内层、外套、腰带、手套、腿部装置、鞋、首饰。注明哪些可脱落、破损、湿润、染血或结霜。任何状态变化必须有发生镜头。

## Body Language

锁定角色习惯：站姿重心、肩线、头部倾向、是否习惯靠近他人、是否先看后动、紧张时哪里泄露情绪。

## Combat Identity

记录：攻击距离、速度类型、主手、武器握法、起手习惯、防御方式、恢复动作、能力触发动作、是否喜欢控制空间或贴身压迫。

## Injury State

伤势记录位置、程度、血迹、活动限制和疼痛反应。伤口不能在下一镜自动消失；疼痛必须影响动作与表演。

## Prompt Use

首次出现写完整角色描述；后续使用稳定Alias，只描述变化。若有参考图，优先依赖参考图而不是重复堆叠外观形容词。

## QC

检查：脸、发型、服装、身高比例、左右手、武器、伤势、站姿和表演习惯是否连续。
