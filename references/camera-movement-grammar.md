# Camera Movement Grammar

## 核心原则

高级运镜不是“镜头一直动”，而是摄影机知道什么时候开始、为什么移动、何时减速、何时停住。每次运动都必须服务信息、Blocking、情绪或空间关系。

## Motion Curve

任何运镜优先写成：

Start → Motivation → Acceleration → Cruise → Deceleration → Settle → Hold

禁止机械匀速移动到结束。真人摄影要保留承载方式带来的轻微惯性和重新构图，但不得随机漂移。

## 基础语法

- Dolly In：压缩心理距离、确认、逼近、进入角色判断。
- Dolly Out：释放、疏离、揭示环境或关系变化。
- Pan：跟随注意力或重新分配画面信息。
- Tilt：高低信息揭示、视线追踪、尺度建立。
- Truck：产生前后景视差，强化空间和关系。
- Pedestal/Crane：改变权力高度、揭示空间或形成垂直转场。
- Arc/Orbit：仅在需要读清前后站位、关系或围绕中心事件时使用。
- Handheld：用于身体临场、危险、主观压力，幅度受控。
- Steadicam/Gimbal：连续调度与人物空间关系。

## 组合语法

- Dolly In + Pan：主体移动中进行注意力锁定。
- Truck + Dolly：制造强视差并改变心理距离。
- Arc + Push：展开双人关系后逐渐聚焦。
- Foreground Wipe + Rack Focus：用前景完成自然转场与信息接力。
- Tilt + Settle：从线索找到主体后停住读取。
- Push-to-Stop：摄影机跟随人物动作同时停止，形成重音。
- Pull-back Reveal：从细节拉回整体，揭示关系或后果。
- POV Reorientation：先建立身体位置，再用头部/视线运动寻找目标。

## Camera Breathing

优先使用：

Move → Settle → Discover → Hold → React → Move

环境本身可以运动：树叶、光斑、云、发丝、衣摆、尘埃。摄影机不必为了“电影感”持续漂移。

## Tilt / Pan 的高级节奏

寻找目标时：启动慢 → 中段自然加速 → 接近目标减速 → 找到目标 → Hard/Soft Settle → Hold 0.5–1秒。

跟随人物时：尽量让人物先触发摄影机，而不是摄影机提前猜动作。

## Dolly Zoom

仅用于空间感或心理空间真正发生变化时。幅度克制，主体大小保持相对稳定，背景透视缓慢改变。禁止把它当“高级感”装饰。

## Action Camera

动作戏首先保证银幕方向和攻击线路可读。高速动作可以让摄影机固定，让动作穿过构图；冲击发生后再短促调整或震动。禁止摄影机和角色同时高速乱跑导致地理关系丢失。

## Physical Support

真人模式必须说明现实承载：Tripod、Dolly、Slider、Steadicam、Handheld、Gimbal、Crane/Jib、Drone、Vehicle Rig、Body Rig。无法真实执行的“幽灵机位”仅在明确风格化模式下允许。

## Prompt Contract

英文摄影提示词以 Camera Movement 开头，并写明：Support + Angle + Lens + Direction + Speed Curve + Subject Distance Change + Settle/Hold + Director Intent。

## Negative

禁止随机漂移、无理由Zoom、机械匀速推拉摇移、持续Orbit、360度炫技、频繁Whip Pan、无来源震镜、摄影机穿越实体、每镜都推近、没有停点。
