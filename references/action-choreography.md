# Action Choreography Direction

## 核心原则

动作戏不是招式展示，而是角色目标、身体物理和空间策略的可视化。每一段动作都必须改变位置、优势、风险或信息。

## Combat Beat

每个战斗Beat至少包含：

Attack → Defense → Counter → Position Change → Tactical Change

如果一轮动作没有改变战术或空间关系，应考虑压缩或删除。

## Body Mechanics

真人动作遵守：Preparation → Weight Transfer → Action → Contact → Compression → Release → Follow Through → Recovery。

必须考虑重力、惯性、摩擦、关节极限、武器重量、受击方向和反应延迟。

## Combat Geography

始终锁定：

- A与B的位置；
- 高低差；
- 攻击轴线；
- 逃生方向；
- 障碍物；
- 谁在逼近、谁在退；
- 每次位移后的新空间关系。

观众可以短暂失去主体，但不能长期失去战场地理。

## Range & Timing

按距离设计：远程、投射、中距、近身、贴身。武器或能力必须有有效距离和启动时间。防守动作要在攻击真正构成威胁后触发，避免提前预知。

## Speed Hierarchy

- Fast：主体仍可读取完整动作。
- High Speed：前景掠过、动作拖尾、镜头压缩。
- Hyper Speed：只读启动、消失、环境反应、命中与新位置。

高速不等于多剪。必要时固定摄影机，让人物穿越构图。

## Multi-Vector Assault

适用于超高速连续斩击：锁定 → 爆发启动 → 消失 → 异位重现 → 单次重击 → 再消失 → 多方向攻击 → 节奏压缩 → 短暂停顿 → 终结击 → 余波。

必须保持攻击方向变化可理解，残像用于时间信息，不是角色复制。

## Impact Design

命中必须包含：接触点、受力方向、局部压缩、身体反应、武器/材质反馈、声音和恢复。不要只用闪光表示命中。

## Tactical Personality

不同角色应有稳定战斗语法：进攻型、控制型、反击型、距离型、诱导型、重击型、速度型。动作风格应反映人物性格与能力规则。

## Action QC

检查：谁主动？谁被迫？每一击是否有距离和准备？人物是否能站稳？受击是否符合方向？镜头是否让动作可读？战斗结束后位置是否与上一Beat连续？
