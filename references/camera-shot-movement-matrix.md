# Shot-to-Camera Movement Decision Matrix

## 核心原则

先决定观众要看什么、人物如何调度，再选择运镜。运镜不是装饰。没有明确叙事理由时，优先固定机位或仅做必要重新构图。

## 运镜选择五问

1. 信息是否正在被发现？
2. 人物与人物的距离是否正在改变？
3. 人物与环境的空间关系是否需要被重新理解？
4. 情绪压力是否正在逼近或释放？
5. 摄影机运动是否比剪切更能保持表演、Blocking或时空连续？

只有至少一项成立，才考虑主动运镜。

## 景别 × 运镜矩阵

### 大远景 / Establishing

适合：
- Static Wide：建立地理、规模、孤独、等待。
- Slow Crane/Pedestal：揭示上下层空间与权力高度。
- Lateral Truck：展示横向地形、队伍、战线。
- Slow Dolly In：从世界尺度进入事件。

避免：无目的Orbit、快速推近、频繁焦段变化。

### 全景 / Full Shot

适合：
- Static：让Blocking和身体动作自己完成叙事。
- Truck：跟随横向移动并保持全身动作可读。
- Steadicam Follow：人物连续走位、穿门、上下楼、多人调度。
- Arc 5–20°：只为读清人物前后关系、武器线或空间变化。

动作戏中，全景优先保证攻击线路和重心，不要摄影机与演员同时高速乱动。

### 中景 / Medium Shot

适合：
- Dolly In：判断、承认、关系逼近、心理压力增长。
- Dolly Out：关系疏离、释放、后果揭示。
- Pan with Actor：注意力跟随。
- Push-to-Stop：人物停下时摄影机同步减速停稳，形成节拍重音。
- Foreground Truck：利用前景视差增加窥视、压迫、空间层次。

### 中近景 / Medium Close-Up

适合：
- Micro Dolly In：人物意识到关键事实、情绪面具裂开。
- Very Slow Truck：细微改变背景关系和权力位置。
- Static + Reframe：真人表演优先，轻微重新构图胜过持续移动。
- OTS Drift：对话中随关系变化进行极轻位移。

禁止每个情绪镜头都自动推近。

### 特写 / Close-Up

适合：
- Static：最常用，让眼神、呼吸和微表演承担变化。
- Micro Push：只用于不可逆认知或情绪压力确实收紧。
- Rack Focus：从眼睛、手、伤口、道具之间转移信息。
- Tiny Handheld：身体压力、惊恐或失衡，但幅度极小。

特写中的大幅Orbit通常会削弱表演真实感。

### 极近特写 / Insert / ECU

适合：
- Macro Dolly：揭示材质、机关、VFX生成源头。
- Tilt/Pan Micro Follow：沿手指、刀刃、伤口、机械结构读取信息。
- Static Insert：动作连续性、关键道具、因果证据。

插入镜头必须服务因果，不要为了“酷”而拍。

## 叙事意图 → 推荐运镜

- 发现目标：POV Tilt/Pan → Decelerate → Settle → Hold。
- 逼近威胁：Controlled Dolly In，主体距离真实缩短。
- 揭示真相：Pull-back Reveal / Crane Reveal / Foreground Wipe + Rack Focus。
- 权力上升：Pedestal/Crane Rise或低机位稳定推进。
- 权力下降：高位、后拉或空间压缩。
- 关系亲近：两人进入同一构图，摄影机可缓推；不要用无意义环绕。
- 关系破裂：Dolly Out、横向分离、建筑遮挡切开画面。
- 跟随行动：Steadicam/Truck/Vehicle Rig，摄影机速度略滞后于人物启动。
- 突然察觉：人物先反应，摄影机后跟；不要摄影机提前知道。
- 失衡/眩晕：克制Dolly Zoom、Dutch或身体化Handheld，仅在剧情成立时。
- 高速攻击：优先固定宽景让动作穿过画面；必要时短促Pan/Truck接力。
- 巨物/规模揭示：先给参照物，再Tilt/Crane/Reveal，不要直接空拍大景。

## 运镜曲线

所有主动运动写明：
Start Frame → Trigger → Acceleration → Cruise → Deceleration → Settle → Hold → End Frame。

高级感来自速度曲线和停点，不来自运镜数量。

## 组合建议

- Dolly In + Pan：移动人物中的注意力锁定。
- Truck + Dolly：强视差 + 心理距离变化。
- Arc + Push：展开关系后聚焦。
- Crane Down + Push：从环境进入人物压力。
- Pull Back + Foreground Reveal：扩大世界并揭示新信息。
- Pan-to-Track：先通过Pan接住人物，再转为平移跟随。
- Tilt-to-Settle：沿线索找到主体后停住。
- Rack Focus + Micro Dolly：信息转移同时改变心理距离。

## 禁止自动化规则

不要根据关键词机械匹配：悲伤≠自动推近，危险≠自动手持，宏大≠自动无人机，战斗≠自动环绕。始终回到戏剧、Blocking、空间和信息。
