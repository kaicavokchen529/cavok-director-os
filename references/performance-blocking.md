# Performance & Blocking Direction

## 核心原则

真人表演优先行为、意图与反应，不用夸张表情代替戏。Blocking不是让演员站好看，而是让人物关系在空间里可见。

## Performance Five Layers

每个关键表演至少考虑：

1. Objective：角色此刻想得到什么。
2. Internal Thought：角色脑中正在判断什么。
3. External Action：身体实际做了什么。
4. Emotional Mask：角色试图让别人看到什么。
5. Leakage：真正情绪从哪里泄露出来，如呼吸、眼神、下颌、手指、肩部或重心。

不要只写“紧张”“愤怒”“警觉”。优先写可观察行为。

## Reaction Logic

真人反应通常遵循：刺激 → 感知 → 认知延迟 → 眼神变化 → 呼吸变化 → 局部肌肉变化 → 身体动作。

认知延迟可约0.1–0.3秒，重大冲击可更长。避免刺激发生后全身同时启动。

## Weight & Posture

任何姿势都要说明：

- 主支撑脚；
- 骨盆方向；
- 胸腔方向；
- 肩线；
- 头部与视线；
- 放松肢体；
- 准备发力的肢体。

身体改变方向前先发生重心转移。人物停止后，头发、衣摆、首饰和呼吸继续产生次级运动。

## Blocking Geometry

先确定：入口、停点、朝向、人物间距离、高低关系、前后关系、光区与暗区、谁挡住谁、谁侵入谁的空间。

关系表达：

- 靠近：信任、依赖、联盟、威胁都可能成立，结合身体朝向判断。
- 拉开：疏离、防御、重新评估。
- 越过：权力侵入或主动夺取空间。
- 让路：主动退让、战术协同或关系尊重。
- 高低差：权力、危险、观察优势。

## Partner Coordination

熟练搭档的动作不应机械串联，而应形成连续动作链。一个人的动作可以成为另一个人的动作触发器。

例如：手肘离开搭档肩膀 → 躯干回正 → 双手直接进入结印，而不是“收手—站直—再结印”。

## Performance Restraint

真人模式默认克制：

- 不持续瞪眼；
- 不长期咬牙；
- 不用夸张胸口起伏表现紧张；
- 不把每个情绪都做成明显脸部变化；
- 允许角色身体放松但眼神高度警觉。

## Blocking QC

每个镜头检查：人物是否能站稳？动作是否符合支撑与惯性？两人关系是否在空间中可读？演员是否像在完成任务而不是摆Pose？摄影机是否服务Blocking而不是逼演员服务镜头？
