# 连续性、终审与持续进化

## Continuity Lock

在场景开始锁定服装、发型、武器、饰品、伤口、血迹、左右手、站位、朝向、道具状态、门窗与建筑结构、光源方向、时间、天气和 VFX 状态。每个 Part 的 End Frame 必须成为下一 Part 的 Start Frame 基准。

## Director QC

- Drama/Information：镜头是否服务剧情，揭示顺序是否准确。
- Performance/Blocking：人物是在表演还是摆 Pose；调度是否表达关系。
- Composition/Camera：第一、第二视觉主体是否清晰；运镜是否有理由。
- Action/VFX：是否有准备、重量、惯性、恢复；特效是否有来源、过程、互动与余韵。
- Lighting/Sound：光源是否有逻辑；声音是否参与叙事。
- Editing/Axis：是否能剪；轴线、视线和银幕方向是否连续。
- Reality：真实演员能否完成；真实剧组如何拍；材质是否过于完美。
- AI：人物、摄影机与画面变化是否分别明确，是否存在滑步、换手、漂移或场景突变风险。

## 持续进化

保持 SKILL.md 为稳定的导演核心；新增经验进入模块，不无限扩写核心。

每个项目结束记录：

1. 项目与场景目标。
2. 原设计及生成/拍摄结果。
3. 哪些地方像电影，哪些地方像 AI。
4. 失败现象、根因和修正。
5. 可复用的新规则候选。

先把候选写入经验记录，经过人工确认和至少一次复现后再纳入对应参考模块。失败案例优先记录可观察症状、原因和修正，不只收藏成功 Prompt。

模块独立版本化，例如 Core、Camera、VFX、Live Action、Sound。参考作品只提炼景别、焦段、调度、光线、剪辑和声音等“导演语法”，不得简单复制表面风格或冒充特定在世创作者。
